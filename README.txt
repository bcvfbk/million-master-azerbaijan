MILLION MASTER AZERBAIJAN

1. Откройте файл index.html двойным щелчком.
2. Интернет и сервер не нужны.
3. Прогресс хранится в LocalStorage браузера.
4. Для переноса прогресса между устройствами в будущем потребуется Firebase или серверная база.
5. Вопросы находятся внутри index.html в массиве QUESTIONS. Их можно расширять вручную или подключить отдельный JSON.

Текущая версия — рабочий локальный MVP. Она демонстрирует архитектуру, дизайн и основные игровые механики.

ОБНОВЛЕНИЕ V7 — СЕРВЕРНАЯ АВТОРИЗАЦИЯ

Теперь сайт необходимо запускать через Node.js, а не двойным кликом по index.html.

ЗАПУСК:
1. Установите Node.js 20 или новее.
2. Откройте терминал в папке проекта.
3. Дополнительные библиотеки устанавливать не нужно.
4. Для локального запуска выполните: npm start
5. Откройте: http://localhost:3000
6. Для публикации задайте переменные OWNER_PASSWORD и SESSION_SECRET на сервере.

Код владельца по умолчанию задаётся в .env:
OWNER_PASSWORD=2020202икслмилионмастераз

ЗАЩИТА:
- Код владельца больше не находится внутри index.html.
- Вход проверяется сервером через криптографическую функцию scrypt и timing-safe сравнение.
- Сервер выдаёт HttpOnly cookie на 8 часов.
- Есть ограничение попыток входа.
- API панели проверяет роль owner.
- Настройки выплат сохраняются в data/private.json с серверной стороны.
- Номер карты клиента сайт не сохраняет.

ВАЖНО:
- Это серверная основа, но платежи всё ещё демонстрационные.
- Для реальных платежей нужно подключить API iyzico/Stripe/другого провайдера и webhook.
- Перед публикацией обязательно использовать HTTPS, настоящий SESSION_SECRET и хостинг с защищённым хранилищем секретов.
